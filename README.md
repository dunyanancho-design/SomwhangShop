\# SomwhangShop - E-Commerce \& WMS Platform



ระบบร้านค้าออนไลน์และระบบจัดการคลังสินค้า (WMS) ครบวงจร พัฒนาขึ้นเพื่อใช้งานจริง รองรับการบริหารจัดการออเดอร์ สต็อกสินค้า ระบบชำระเงิน และระบบ Automation เชื่อมต่อกับ Social Media



\---



\## 🚀 Tech Stack (เทคโนโลยีที่ใช้)

\* \*\*Frontend / Backend:\*\* Blazor Server (.NET 10), C#

\* \*\*Database:\*\* MySQL

\* \*\*Database Management:\*\* Entity Framework Core

\* \*\*Integration \& Automation:\*\* Facebook Page Bot, LINE Bot, Thunder API (ตรวจสอบสลิปโอนเงินอัตโนมัติ)

\* \*\*Deployment \& Networking:\*\* Cloudflare Tunnel, Local Server



\---



\## ✨ Key Features (ฟีเจอร์เด่นของระบบ)

\* \*\*ระบบตระกร้าสินค้า \& ชำระเงิน:\*\* รองรับการคำนวณค่าจัดส่งตามน้ำหนัก (Weight) และจำนวนชิ้น (Quantity) พร้อมระบบเช็คสลิปโอนเงินอัตโนมัติ

\* \*\*ระบบจัดการคลังสินค้า (WMS):\*\* ควบคุมสต็อกสินค้า จัดการหมวดหมู่ และบันทึกประวัติการเข้าชมสินค้า

\* \*\*ระบบตัวแทน (Affiliate):\*\* ติดตามและบันทึกสถิติการเข้าชมของตัวแทนจำหน่ายแต่ละคน

\* \*\*ระบบแชทบอทอัตโนมัติ (Auto-Reply):\*\* ตอบกลับข้อความและจัดการเพจ Facebook อัตโนมัติ

\* \*\*ระบบแดชบอร์ดสรุปยอด:\*\* แสดงสถิติยอดขาย การเข้าชมเว็บไซต์ และสถานะคำสั่งซื้อ
